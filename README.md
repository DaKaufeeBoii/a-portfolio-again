## 🕹️ Secret Game: Katamari Damacy (Kathack-Inspired)

The portfolio features a secret, fully interactive **Katamari Damacy** game inspired by the legendary **Kathack** bookmarklet:

* **The Portfolio IS the Map**: The game runs directly on the live website. The Katamari ball rolls across the entire document height (~9,000px) from the Hero section down through Projects, Simulator, Experience, Skills, and Contact.
* **Volumetric Absorption**: Uses Kathack's volumetric collision formula ($V = W \times H \times \min(W, H)$). When the ball rolls over badges, buttons, text, or cards, elements smaller than the ball are absorbed and physically attached to the 3D rotating sphere.
* **Unhindered Traversal**: Large elements do not block or trap the ball—the Katamari glides smoothly over them, vacuuming up smaller items until it grows large enough to absorb the entire card!
* **King of All Cosmos Dialogue**: Displays royal commentary as you roll up Sai Tarun's tech stack.
* **Clean Non-Destructive Reset**: Exiting or clicking "Reset Page" instantly unhides all DOM elements back to their pristine states.

### How to Trigger Katamari:
1. Click the coffee cup button (**☕**) at the bottom-left corner of the screen.
2. Type **`katamari`** anywhere on your keyboard.
3. Enter the Konami Code: <kbd>↑</kbd> <kbd>↑</kbd> <kbd>↓</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> <kbd>←</kbd> <kbd>→</kbd> <kbd>B</kbd> <kbd>A</kbd>.
4. Press <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> to open the Command Palette and select **"🎮 Play Katamari — Roll up the portfolio!"**.

## 🛠️ Local Development

### Prerequisites
* Node.js 18+
* npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/DaKaufeeBoii/a-portfolio-again.git
cd a-portfolio-again

# Install dependencies
npm install

# Run the development server
npm run dev
```

Visit `http://localhost:5173` to explore the portfolio.

### Production Build

```bash
# Type check and build production bundle
npm run build

# Preview production build locally
npm run preview
```
